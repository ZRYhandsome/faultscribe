## FaultScribe 0.1.0 — 2026-09-20 (local development release candidate)

### Added

- Local `doctor` command with a fixed version-query allowlist and per-command timeout.
- Local Markdown/JSON report generation from explicitly selected inputs.
- Best-effort, non-destructive UTF-8 text-log redaction with preview and replacement summary.
- English and Chinese documentation, contribution/privacy boundaries, issue forms, unit tests, and minimal-permission CI configuration.

### Fixed

- Corrected the CI help check to use the released `faultscribe` command after the project rename.
